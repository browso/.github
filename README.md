# Browso

> **AI-Powered Web Browser**

[Website](https://www.browso.org) · [LinkedIn](https://www.linkedin.com/company/browso) · [GitHub](https://github.com/browso) · [Hugging Face](https://huggingface.co/browso)

## Overview

**Browso** is creating a next-generation web browser enhanced with artificial intelligence, helping users search, understand, and interact with the web more efficiently.

Through intelligent browsing features, Browso seeks to support users in accessing relevant information faster, reduce friction in everyday online tasks, and make browsing more productive, contextual, and user-focused.
